마크다운을 PDF로, 버튼 하나로

md 파일을 아래에 끌어다 놓고 PDF 버튼을 누르면 미리보기에 보이는 그대로 PDF가 됩니다.

여기에 md 파일을 끌어다 놓으세요또는 클릭해서 파일 선택 · 설치 없음 · 서버 전송 없음

md 파일을 PDF로 저장하는 방법

  1. md 파일을 이 페이지나 readmd.kr에 끌어다 놓습니다.
  2. 오른쪽 미리보기에서 서식이 제대로 보이는지 확인합니다. 필요하면 왼쪽에서 고칩니다.
  3. 상단의 PDF 버튼을 누릅니다. 브라우저 인쇄 창이 열립니다.
  4. 대상(프린터)을 "PDF로 저장"으로 고르고 저장합니다.
제목, 표, 목록, 코드 블록, 체크리스트가 화면에 보이는 그대로 PDF에 들어갑니다. 편집기와 버튼은 빠지고 문서만 인쇄됩니다.

변환 사이트에 올리지 않아도 되는 이유

마크다운 PDF 변환 사이트는 대부분 파일을 서버에 올려서 변환한 뒤 내려받게 합니다. 회사 문서나 계약 내용이 담긴 파일이라면 꺼림칙합니다.

ReadMD는 파일을 브라우저 안에서 서식으로 바꾸고, PDF는 브라우저의 인쇄 기능으로 만듭니다. 파일이 컴퓨터 밖으로 나가지 않습니다. 회원가입도, 하루 변환 횟수 제한도 없습니다.

보기 좋게 뽑는 팁

  • 인쇄 창에서 여백을 "기본" 또는 "좁게"로 두면 A4 한 장에 더 많이 들어갑니다.
  • 표가 넓으면 가로 방향으로 바꾸세요.
  • 배경 그래픽 옵션을 켜면 코드 블록의 회색 배경과 인용문 표시가 유지됩니다.
  • PDF 대신 HTML로 내보내면(HTML 버튼) 메일이나 메신저로 보냈을 때 받는 사람이 바로 열 수 있습니다.

자주 묻는 질문

md를 PDF로 바꾸는 데 돈이 드나요?

아니요. ReadMD는 무료이고 횟수 제한이 없습니다.

워드(docx)로도 바꿀 수 있나요?

HTML로 내보낸 뒤 워드에서 열면 서식이 대부분 유지됩니다. 바로 .docx로 내보내는 기능은 준비 중입니다.

PDF에 편집기 화면도 같이 나오나요?

아니요. 인쇄할 때는 미리보기 문서만 나오고 편집기와 버튼은 빠집니다.

휴대폰에서도 PDF로 저장되나요?

네. 휴대폰 브라우저의 공유/인쇄 메뉴에서 PDF로 저장을 고르면 됩니다.

파일을 끌어다 놓기만 하면 됩니다. 설치도 가입도 없습니다.
