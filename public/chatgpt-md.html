ChatGPT·Claude가 준 md 파일, 바로 읽기

AI가 만들어 준 .md 파일을 아래에 끌어다 놓으세요. 제목, 표, 체크리스트가 제대로 보입니다.

여기에 md 파일을 끌어다 놓으세요또는 클릭해서 파일 선택 · 설치 없음 · 서버 전송 없음

AI는 왜 md 파일로 주나요

ChatGPT, Claude, Gemini 같은 AI는 답변을 마크다운으로 씁니다. 제목은 #, 목록은 -, 표는 |로 표시하는 방식이라, 문서로 내보낼 때도 그대로 .md 파일이 됩니다. 채팅 화면에서는 예쁘게 보였는데 파일을 열면 기호만 보이는 이유가 이것입니다.

워드 파일로 달라고 하면 되지만, 표나 코드가 깨지는 경우가 많아서 md 파일 그대로 받아 뷰어로 여는 편이 깔끔합니다.

받은 md 파일 여는 방법

  1. AI가 준 파일을 내려받습니다. 보통 보고서.md, 정리.md 같은 이름입니다.
  2. 브라우저에서 readmd.kr을 열고 파일을 끌어다 놓습니다. 이 페이지에서도 됩니다.
  3. 서식대로 보이면 그대로 읽고, 고칠 부분은 왼쪽에서 고칩니다.
  4. .md 저장으로 다시 내려받거나, PDF로 저장해서 공유합니다.
Claude Code나 Cursor 같은 도구가 프로젝트 폴더에 만들어 주는 README.md, PLAN.md 같은 파일도 똑같이 열립니다.

AI 문서를 다룰 때 편한 기능

  • 여러 파일 동시 열기: 한 번에 만들어 준 문서 여러 개를 끌어다 놓으면 탭으로 나뉩니다.
  • 목차: 긴 보고서는 왼쪽 목차로 바로 이동합니다.
  • Mermaid 다이어그램: AI가 그려 준 순서도·구조도가 그림으로 보입니다.
  • 체크리스트: 할 일 목록이 체크박스로 보입니다.
  • 서버 전송 없음: AI에게 물어본 회사 자료를 다시 어디에 올릴 필요가 없습니다.

자주 묻는 질문

ChatGPT가 md 파일을 안 주고 화면에만 보여 줘요.

"이 내용을 .md 파일로 만들어서 다운로드 링크를 줘"라고 요청하면 파일로 줍니다. 아니면 답변을 복사해서 ReadMD의 '새 문서'에 붙여 넣어도 됩니다.

Claude 아티팩트로 받은 md도 되나요?

네. 내려받은 .md 파일을 끌어다 놓으면 됩니다.

AI가 준 파일을 고쳐서 다시 AI에게 줄 수 있나요?

네. 왼쪽에서 고친 뒤 .md 저장으로 내려받아 다시 올리면 됩니다.

문서 내용이 어디로 전송되나요?

아무 데도 가지 않습니다. 브라우저 안에서만 처리됩니다.

파일을 끌어다 놓기만 하면 됩니다. 설치도 가입도 없습니다.
